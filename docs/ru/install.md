# Установка Poly — 2 минуты, без технических навыков

Poly — это команда для iPhone: задаёте один вопрос, и его обрабатывают сразу два ИИ — ChatGPT и Claude — в одном из одиннадцати режимов. Ответ приходит на экран и в буфер обмена.

## Что нужно ДО установки (один раз)

1. **iPhone с iOS 18 или новее.** Это официальный минимум самого действия «Спросить Claude», на котором держится дуэт (Anthropic прямо пишет «iOS 18 и новее» в своей справке). Отдельно от этого, по спискам Apple под iOS 26 подходят iPhone 11 и новее, SE 2-го поколения и новее; сам Poly НЕ требует Apple Intelligence — только iOS 18+. iPad — ожидаемо работает на iPadOS 18+/26, но вживую не проверялся. Спутнику **Poly Compress** нужно железо Apple Intelligence: чип A17 Pro / M-серии и новее (это iPhone 15 Pro/Pro Max, любые 16/16e и новее; iPad с M1+ или mini с A17 Pro).
2. **Установленные приложения ChatGPT и Claude** из App Store, в обоих выполнен вход. Хватает бесплатных аккаунтов: бесплатный Claude — Sonnet 5.5, та же модель, что у платного, а действие «Ask Claude» берёт модель, выбранную в приложении Claude.

## Установка (в один тап)

### Самый простой способ — ссылка iCloud (одно касание)

На iPhone тапните ссылку → откроются «Быстрые команды» → **«Добавить»**. При первом запуске команда 4–6 раз спросит разрешения — каждый раз жмите **«Разрешать всегда»**.

- **Duo:** https://www.icloud.com/shortcuts/62ba03c01b77478395108c671d2f6c94
- **Trio** (третий голос, см. ниже): https://www.icloud.com/shortcuts/9b29f1f7207f49c194dda7856b3474ff

### Запасные способы — файл

Подписанные файлы `Duo.shortcut` и `Trio.shortcut` лежат на сайте [polyhelper.ai/duo/ru/](https://polyhelper.ai/duo/ru/) и в [GitHub-релизе](https://github.com/vadimchernets/c1m-duo/releases/tag/v1.0.0). Или так:

1. Получите файл **`dist/ru/Poly.shortcut`** любым способом: AirDrop, WhatsApp/Telegram, почта, флешка — как угодно.
2. Тапните по файлу → откроется приложение «Команды» с карточкой «Poly» → нажмите **«Добавить»**. Всё, команда установлена.
   - Если файл пришёл в мессенджер: сначала тапните его там, выберите «Поделиться»/«Открыть в…» → «Команды».
3. **Первый запуск:** команда спросит разрешения — «Разрешить действия ChatGPT?» → Разрешить; «…отправить текст Claude?» → **Разрешать всегда**; «…скопировать в буфер?» → **Разрешать всегда**. Это одноразовое.

## Иконка на экран «Домой» (30 секунд, по желанию)

1. Откройте «Команды» → долгое нажатие на плитку Poly → если меню не появилось, тапните «···» на плитке → вверху тапните имя **Poly ⌄** → **«На экран „Домой"»**.
2. Хотите фирменную иконку? Тапните миниатюру → вкладка «Изображение» → «Выбрать фото/файл» → выберите `assets/poly.jpg` (перекиньте её на телефон вместе с командой).
3. «Добавить». Иконка Poly появится на рабочем столе — запуск в один тап. Голосом: «Привет, Siri, Poly».

## Как пользоваться

Тап по иконке → «Вопрос для Poly?» → пишите вопрос → «Готово» → выберите режим. Меню двухуровневое: сверху — шесть частых режимов, остальные — опциями в «📂 Ещё…» (ничего не удалено, редкому режиму — один лишний тап). Там же пункт **ℹ️ Что такое Poly** — бесплатная справка по всем режимам прямо на телефоне: растерялись при запуске — зайдите туда, ни одного сообщения она не тратит.

**Главное меню (частые режимы):**

| Режим | Что происходит | Расход |
|---|---|---|
| **⚖️ Критика · 2✉** | ChatGPT отвечает, Claude проверяет и выдаёт улучшенный финал. Режим на каждый день. | 2 сообщения |
| **🤝 Спор до согласия · 3–8✉** | Для жизненных решений без правильного ответа («что выбрать», «соглашаться ли»). ChatGPT занимает сторону, Claude возражает, ChatGPT отвечает — до 3 кругов, пока один честно не уступит. В конце: где сошлись, где остался спор, что решить Вам. | 3–8 сообщений |
| **🩺 Советник · 1✉** | Claude проверяет ВАШ готовый текст, не переписывая: вердикт одной строкой, самое сильное возражение — первым, что стоит перепроверить. Самый дешёвый режим. | 1 сообщение |
| **👀 Опрос · 2✉** | Оба отвечают независимо, ответы — рядом. | 2 сообщения |
| **🔀 Синтез · 3✉** | Оба отвечают вслепую, потом сборка «якорь + дельта». Спросит, кто якорь: Claude (факты/структура) или ChatGPT (тон/креатив). Для всего, что важно. | 3 сообщения |
| **🧭 Авто · +1✉** | Не знаете, какой режим взять? ChatGPT подберёт сам (+1 сообщение), затем Poly перезапустится с тем же вопросом — выберете рекомендованный режим. | 1 сообщение + режим |

**📂 Ещё… (редкие режимы + бесплатная справка):**

| Режим | Что происходит | Расход |
|---|---|---|
| **⚔️ Решение · 3✉** | Быстрый взгляд (ChatGPT) встречается с осторожным (Claude), затем рефери даёт первые шаги и риски. Для решений. | 3 сообщения |
| **🗺 Карта спора · 3✉** | Оба отвечают вслепую, затем карта: где согласны, где расходятся, слепые зоны, что проверить. Без навязанного вывода — решаете сами. | 3 сообщения |
| **🥊 Дебаты · 4✉** | Черновик → оппонент ищет слабости → пересмотр → вердикт судьи. Для самых сложных задач. | 4 сообщения |
| **❓ Уточнение · 2✉** | ChatGPT сначала спрашивает, чего не хватает → вы отвечаете в появившемся окне → Claude даёт точный ответ. Для размытых вопросов. Единственный режим, где посреди прогона нужно тронуть экран — но только в его собственном диалоге, больше нигде. | 2 сообщения |
| **🎨 Картинка · 2–3✉** | Опишите, что нарисовать → оба ИИ-художника рисуют вслепую (векторный SVG, каждый в чистой сессии — не подсматривают друг за другом) → откроется страница с двумя эскизами рядом, ◆ CLAUDE и ◆ CHATGPT — выбирайте (спросят: только эскизы · 2✉ или + вердикт судьи-сравнения · 3✉ — судья сравнивает код эскизов, а рендеры вы и так видите сами). Картинка сохраняется (Файлы → iCloud Drive → Shortcuts → `Poly-image.html`), а SVG-код попадает в буфер: вставьте его в любой конвертер или сайт — получите файл картинки любого размера. | 2–3 сообщения |
| **➕ Дельта · 2✉** | Claude пишет якорный ответ → ChatGPT возвращает ТОЛЬКО список усилений, без пересборки. Дешёвая альтернатива Синтезу, если жалко лимит сообщений. | 2 сообщения |
| **ℹ️ Что такое Poly** | Справка на экране: что это и какой режим когда брать — без единого вызова ИИ. Оттуда «🔁 Другой режим» вернёт к выбору режима с тем же вопросом. | 0 сообщений |

**Быстрый вход без меню** (по желанию): поставьте рядом спутник **Poly Quiet** — это готовая Критика в один тап вообще без выбора режима (итог сразу в буфер и журнал, без экранов), или **Poly Voice** — то же голосом и с озвучкой финала. Иконку любого из них можно вынести на «Домой» так же, как Poly, — получится «быстрая кнопка» рядом с полным меню.

Цена видна прямо в меню (значок ✉). По ходу работы приходят уведомления прогресса «[шаг 2/4]…». Журнал пишет и режим, и сырьё (промежуточные ответы моделей) — если финал оборвался, черновики не пропали. Финал открывается на весь экран с кнопкой «Поделиться» (Quick Look).

**Два уровня системы.** Уровень 1 — ядро: пара Poly и спутники ниже, которые после тапа работают сами — начинайте отсюда, это и есть суть. Уровень 2 — **🎼 Poly Multi**: та же пара плюс любые другие ИИ, что у вас есть, подключаются полумеханически: Poly пишет промпт, ведёт вас по приложениям по очереди и сводит всё в один документ, а вы вставляете, отправляете и копируете. Примерно половина той работы, что раньше делалась руками. Ставится рядом с ядром — берите, когда пара станет привычной.

**Спутники-автоматы Poly** (в комплекте): **Poly Voice** — тап → сразу диктовка → конвейер Критики → финал вслух (для ходьбы и кухни); **Poly Photo** — поделитесь фото или PDF → текст распознаётся на устройстве (OCR, бесплатно, без сети) и сам уйдёт в Poly; **Poly Quiet** — то же, что Критика, но без уведомлений и финального экрана: итог только в буфер и журнал (для запусков «между делом»); **Poly Compress** (только устройства с Apple Intelligence: iPhone 15 Pro и новее, вся линейка 16/16e/17) — выделили простыню текста → Поделиться → Сжатие: бесплатная встроенная модель Apple ужимает текст и сама запускает Poly (защита от таймаута на длинных текстах).

Сразу после выбора режима придёт **уведомление со статусом** («что происходит и сколько ждать»). Дальше ~1–2 минуты ожидания → ответ на экране и уже в буфере обмена. Готовые формулировки под 20+ типовых задач — в [`recipes.md`](recipes.md). Финал всегда начинается с сути одной строкой, в конце — «Уверенность: высокая/средняя/низкая». **Пока команда работает — не трогайте телефон**: прикосновение к экрану отменяет её (если «тихо умерла» — просто запустите заново). Исключение — режим ❓ Уточнение: он сам, по плану, откроет второе окно и попросит ответить на уточняющие вопросы (или тапнуть «пропустить») — это не сбой, а часть сценария: впишите ответ, и команда продолжит сама.

## Суперсилы

- **Из любого приложения:** выделили текст → «Поделиться» → Poly — вопрос уже подставлен в окно, можно дописать «переведи/проверь/объясни» и запускать.
- **Журнал:** каждый прогон сам дописывается в файл `Poly-journal.md` (Файлы → iCloud Drive → Shortcuts). Вся история вопросов и вердиктов в одном месте; при первом прогоне разрешите доступ к файлу («Разрешать всегда»).
- **Запуск без рук:** Настройки → Кнопка действия (Action Button) → «Быстрая команда» → Poly. Или двойной тап по задней крышке: Настройки → Универсальный доступ → Касание → Тап по задней панели → Poly. Голосом: «Привет, Siri, Poly».
- **Ещё точки входа:** виджет на главный/заблокированный экран (долгий тап по столу → + → Shortcuts → Poly); Пункт управления (Настройки → Пункт управления → добавить «Быстрые команды»); NFC-метка на столе/в машине (Команды → Автоматизация → NFC → запустить Poly).
- **Фото в дуэт:** главный путь — спутник **Poly Photo** (поделитесь фото/PDF → OCR → сам запустит Poly). Для смыслового разбора снимка (не текста на нём): виджет Claude «камера» → разбор → Copy → поделитесь текстом в Poly.
- **Проверить свой текст:** выделили свой черновик где угодно → Поделиться → Poly → режим 🩺 Советник — он проверит, не переписывая (и не превратится в соавтора).
- **На iPhone 15 Pro и новее:** в Командах есть действие «Использовать модель» (Apple Intelligence, бесплатно и без интернета) — им можно дополнять Poly, например авто-выбором режима. На iPhone 14 и старше действие недоступно, Poly работает без него.
- **Голос сразу при запуске (по желанию):** в редакторе раскройте первое действие «Спросить» и включите тумблер немедленной диктовки — тогда тап по иконке сразу слушает вопрос голосом. По умолчанию выключено (удобнее и для текста, и для шэр-щита).

## Trio — третий голос (бесплатный ключ)

`Trio.shortcut` добавляет к паре третий ИИ: он читает вопрос, ответ ChatGPT и итог Claude и
называет только то, что пропустили оба. Работает на **любом бесплатном ключе — или нескольких**,
спрашивает один раз.

**Бесплатные ключи — каждый за минуту, без карты** (хватит одного; больше ключей — Трио почти никогда не молчит):
- **aistudio.google.com/apikey** → Create API key (Gemini, начинается с `AIza`);
- **openrouter.ai/keys** → Create key (десятки бесплатных моделей разных компаний, начинается с `sk-or-`);
- **console.groq.com/keys** → Create API Key (начинается с `gsk_`).

Запустите Trio и вставьте ключ(и), когда он спросит, — несколько ключей, каждый с новой строки. Они
лежат в iCloud Drive → Shortcuts → `poly-key.txt`, не в ярлыке. При первом запуске iPhone 4–5 раз
спросит разрешение — каждый раз сразу нажимайте **«Разрешить»** (окно без ответа закрывается, и
ярлык пишет «не может получить доступ»).

Трио перебирает все ключи и все бесплатные модели, пока кто-то не ответит: перегруженная модель или
исчерпанный дневной лимит — следующая модель, ключ без денег или неверный — пропускается. Только если
не ответил никто, Трио пишет, что ответил каждый (кончились деньги, лимит, перегружен, неверный ключ),
и что сделать. Добавить ключ потом: новой строкой в `poly-key.txt` («Файлы» → iCloud Drive →
Shortcuts) или удалите файл и запустите Trio снова.

## Про iCloud — платить НЕ нужно

Poly НЕ требует платного iCloud. Ядро (вопрос → оба ИИ → ответ на экран и в буфер) вообще не трогает облако. iCloud касаются только две необязательные удобности: журнал прогонов и файл картинки — это килобайты, бесплатных 5 ГБ любого Apple ID хватает на десятилетия такой записи. Если iCloud Drive выключен или переполнен — ответ всё равно придёт на экран и в буфер (проверено конструкцией), не запишется только журнал. Не нужен журнал вовсе — см. «Приватность» ниже.

## Приватность

Журнал `Poly-journal.md` хранит все ваши вопросы и ответы открытым текстом в iCloud Drive. Не хотите истории — удалите в редакторе действие журнала; уже накопленное стирается удалением файла `Poly-journal.md` в Файлах. Разросся журнал — просто переименуйте файл (например, в `Poly-журнал-август.md`): новый создастся сам при следующем прогоне.

## Если что-то не так

- **ChatGPT: «You are logged out»** (при живом логине) — откройте приложение ChatGPT, закройте, запустите Poly заново. Известный глюк, лечится всегда.
- **Claude: «This model isn't available right now»** — кончился дневной лимит бесплатного Claude или в приложении Claude выбрана модель не из вашего плана. Выберите Sonnet в приложении Claude или дождитесь сброса лимита; пока лимит — проверяет Трио, бесплатный ИИ по ключу.
- **Claude молчит / пустой ответ на длинном вопросе** — у действия Claude есть таймаут: он возвращает управление раньше, а Claude ДОПИСЫВАЕТ ответ в самом приложении. Откройте Claude, ответ там, скопируйте кнопкой приложения. На будущее: короче вопрос — надёжнее возврат. Если просто сбой — смахните «Команды» из недавних и запустите заново.
- **Пересылаете Poly кому-то:** шлите `Poly.shortcut` отдельным файлом, не архивом (zip на телефоне — лишние шаги). В Телеграме: долгое нажатие на файл → Поделиться/Сохранить в Файлы, не одиночный тап.
- **Не переименовывайте команду Poly.** Спутники Фото и Сжатие и кнопка «🔁 Другой режим» зовут её строго по имени «Poly»: переименуете (или при повторном импорте появится «Poly 1») — эти три пути молча перестанут работать. Если при переустановке появился дубль: удалите старую команду, оставьте имя ровно «Poly».
- **Ответы слабее ожидаемого** — действие берёт модель по умолчанию из приложения Claude: откройте Claude, переключите модель, закройте, запустите Poly заново. Хорошая привычка: перед важным прогоном загляните в Claude и проверьте модель в шапке.
- **Из шэра прилетела голая ссылка и ничего не вышло** — действия не читают веб-страницы сами: откройте страницу, выделите кусок текста и поделитесь куском.
- **Бонус:** финал попадает в общий буфер (Universal Clipboard) — на Mac/iPad его можно сразу вставить через Cmd+V, телефон трогать не нужно.
- **После крупного обновления iOS** (например, на iOS 27) сделайте один контрольный прогон Критики: большой апдейт Команд может заново спросить разрешения или показать лишнюю карточку «Готово» — один прогон это выявит и вылечит.
- Расход сообщений идёт из **подписок** обоих сервисов (не из API), лимиты общие с обычными чатами. Модель — та, что стоит по умолчанию в каждом приложении.

## Что дальше после финала

Под финальным экраном Poly спросит: **«✅ Готово»** или **«🔁 Другой режим — тот же вопрос»** — второй пункт перезапустит Poly с уже подставленным вашим вопросом (можно подправить) и даст выбрать другой режим. Удобно: спросили Критику → тут же прогнали Карту спора без перенабора.
